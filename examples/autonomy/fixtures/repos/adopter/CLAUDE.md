# Adopter project

Fixture repository for the census test.

## Commands

- Run the tests with `npm test`.
- Run the linter with `npm run lint`.

## Constitutional rules

1. Every change is reviewed by someone other than its author.
2. Agent commits carry a Co-Authored-By trailer naming the human of record.
3. Agents never edit `.autonomy.yaml`, CODEOWNERS or files under `.github/workflows/`.
